# ⏱️ Digital Clock — SpireX Foundation Task 6

A modern, responsive, and interactive **Digital Clock** built using **HTML, CSS, and JavaScript**.

The clock displays the current local time in a stylish 12-hour format with AM/PM, along with the current date. It updates automatically every second without requiring a page refresh.

## ⚙️ How It Works

JavaScript retrieves the user's current local time using:

```javascript
new Date();
```

The hours, minutes, and seconds are formatted and displayed dynamically.

The clock is updated every second using:

```javascript
setInterval(updateClock, 1000);
```

The current date is also generated automatically using JavaScript's `toLocaleDateString()` method.
